# Test-Print Index — manual dimension entry

156 part prints not yet run through Machinable. Open each PDF (in this folder) and fill the row.

Scope note: only parts machined FROM PURCHASED STOCK belong here. Part-specific
castings/forgings (you machine the supplied blank, no stock to buy) are out of scope —
flag any you spot while filling this in and I'll drop them.

**How to fill each row:**
- **Shape**: `CYL` (round/turned) or `CUBE` (flat/prismatic).
- **Units**: `IN`, `MM`, or `IN+MM` (dual-dimensioned — record the PRIMARY units).
- **Dims — NOMINAL only, ignore tolerances** (`9.52 +/- 0.12` -> `9.52`):
  - CYL -> fill **Dia** (max outside diameter) and **L** (overall length).
  - CUBE -> fill **Thk**, **W**, **L** (overall).
- **Bounding envelope** = smallest stock the finished part fits inside (largest OD / overall dims, include protrusions) — not a feature/detail dimension.
- **Material**: callout as written. **Notes**: anything tricky (multi-page, no overall dim, casting, etc.).

## Caterpillar Parts — PARKED (handwritten prints, not a tuning target)

**PARKED — these never run.** Every Caterpillar print is handwritten, which is
the rarest thing this app will ever see, so we are not calibrating for it. Any
row here with dimensions filled in is skipped by the eval. If vision can't read
handwritten dimensions, that is an acceptable answer — do not change a prompt,
a threshold, or any code to improve a Caterpillar score. Revisit only if
there's spare time.

**No material is specified on any Caterpillar print.** The engineer left it
off. That is fine and expected — not a failure, and not something to fix.

The PDFs stay in this folder with everything else; only the runs skip them.
